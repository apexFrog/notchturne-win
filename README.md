# Описание (поле About, англ.):
Dynamic Island-style music panel for Windows: album art, synced lyrics, playback controls and clipboard history at the top of your screen. Works with Spotify, Apple Music and any player that shows up in the Windows media controls.

Описание по-русски:
Остров с музыкой вверху экрана Windows: обложка, синхронные тексты песен, управление плеером и история буфера обмена. Работает со Spotify, Apple Music, Яндекс Музыкой и браузером.
